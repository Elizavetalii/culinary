О приложении:
Art Culinary CRM - корпоративная CRM-система для ООО «АРТ КУЛИНАРИЯ». Система автоматизирует работу с клиентами, заказами, производственными ограничениями, сборкой заказов, доставками, маршрутами, внутренними сообщениями, отчетами, аналитикой и резервным копированием.

- Django 6
- PostgreSQL 16+
- Django REST Framework
- drf-spectacular для документации API

Основные роли пользователей:
- Менеджер: клиенты, заказы, аналитика, отчеты, проверка доставок.
- Логист: доставки, курьеры, маршруты, остановки, статусы маршрутов.
- Сборщик заказов: контроль заказов в производстве и сборке.
- Курьер: выполнение доставок и подтверждение доставки.
- Администратор системы: пользователи, роли, отчеты, резервные копии, системные настройки.

- crm: базовые сущности, роли, клиенты, блюда, ингредиенты, заказы, производственные ограничения.
- accounts: авторизация, выход, восстановление пароля, перенаправление по ролям.
- dashboard: панели менеджера, логиста, сборщика и администратора.
- clients: клиентская база, контакты, этапы сотрудничества, история взаимодействий.
- orders: оформление заказов, статусы, архив, проверка ограничений, рабочее место сборщика.
- logistics: доставки, курьеры, маршруты, остановки, подтверждения доставки.
- reports: отчеты, аналитика, экспорт в файлы.
- admin_panel: административная панель, пользователи, роли, резервные копии.
- communications: внутренние сообщения и комментарии к объектам.
